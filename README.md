# Save Data Toolkit

Save Data Toolkit is a Windows desktop toolkit for inspecting and safely editing supported game save files. This repository is being prepared as a free, open-source Core preview by YuniWorks. No public Windows release or code-signing approval is claimed here.

The Core works without a paid Compatibility Pack. You can inspect an unknown file in Generic Safe File Mode, view its size and SHA-256, make a verified backup, and restore it as a new file. The included Synthetic Demo provides a full editing workflow without a commercial game or ROM.

## Preview features

- Signed declarative pack loading, trust checks, and a synthetic demo pack
- Generic save fields, slots, table and inspector views, search, favorites, Simple/Advanced views, in-app guide, tutorial, and custom Quick Edit
- Backup and restore-as-new, validation, integrity checks, diff, change set, apply, verify, and rollback
- Japanese and English interface

The editing path is **Backup → Validate → Diff → Apply → Verify → Rollback**. The original save is opened read-only; edits use a working copy and export to a new file. Unsupported files stay read-only in Generic Safe File Mode. A signed pack establishes provenance and integrity, not a purchase entitlement.

## Platform and status

The confirmed preview environment is Windows 11 x64. Windows compatibility details are being finalized; Windows 10 support is not claimed here. Building requires the .NET SDK version pinned in `global.json` (10.0.400). This is preview source documentation, not an announcement of a published binary, Microsoft Store listing, or SignPath approval.
