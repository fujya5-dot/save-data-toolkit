# Unsigned OSS Preview release notes template

> Draft for a future GitHub Release. No binary release has been published yet.

Save Data Toolkit 0.1.0 is an OSS Core preview under MPL-2.0. This is an **unsigned** Windows x64 portable ZIP; it is **not** approved or signed by SignPath Foundation. Windows 11 x64 is the confirmed environment. Extract the ZIP and run `YuniRetroToolkit.App.exe`; see [Building and removal instructions](BUILDING.md). SHA-256 for the ZIP is published in `ARTIFACTS-SHA256.txt`, and per-file hashes are inside the ZIP.

The included Synthetic Demo exercises the editing workflow without a ROM or commercial save. The Core also provides Generic Safe File Mode. No paid Compatibility Pack is required to use the Core or Demo, and no proprietary pack is in this release.
